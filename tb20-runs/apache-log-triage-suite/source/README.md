# Apache Log Triage Suite

Terminal-Bench 2.0 style dataset with one web-network-services scenario at three difficulty levels:

- `easy/apache-log-triage-easy`
- `medium/apache-log-triage-medium`
- `hard/apache-log-triage-hard`

The tasks exercise Apache access-log parsing, rotated log handling, deterministic reporting, and incident-style aggregation.
